# Connecta Focus — ข้อเสนอ demo

สถานะ: ยืนยันขอบเขตและความเข้าใจร่วมกันแล้วจากคำตอบ Q1–Q51 ยังไม่เริ่มพัฒนาตามคำขอให้เสนอไว้ก่อน

## ปัญหาและคุณค่า

ช่วยนักศึกษาที่มีงานชัดเจน แต่ทำงานคนเดียวแล้วเลิกก่อนบรรลุเป้าหมายรายรอบ ผ่านวงจรตั้งเป้าหมาย → ทำงานพร้อมเพื่อน → สะท้อนผล ปัญหาและประสิทธิผลยังเป็นสมมติฐานที่ต้องทดสอบ กลุ่มแรกคือผู้ทำ assignment หรืออ่านสอบรายบุคคล

## ขอบเขต

ผู้ใช้พัฒนา demo คนเดียว เน้น Desktop ใช้โลก Cozy Campus Library แมพเดียว พร้อม UI Calm Study Workspace ตามไฟล์ข้อเสนอฐาน ห้องส่วนตัวผ่านรหัส สูงสุด 8 คน มี 2 โต๊ะ โต๊ะละ 4 ที่นั่ง ทุกห้องใช้เลย์เอาต์เดียวกันแต่แยกสถานะ

บัญชี ชื่อเล่น อวาตาร์สำเร็จรูป การเดิน WASD/ลูกศร collision และ E โต้ตอบกับวัตถุเป็นส่วนของ demo ปุ่ม UI ใช้เลือกที่นั่ง ตั้งเป้าหมาย และดูประวัติได้ด้วย ไม่รับคำสั่งเดินหรือ interact ขณะพิมพ์

วัตถุหลัก: โต๊ะ/เก้าอี้สำหรับนั่งและร่วมรอบ กระดานเป้าหมายสำหรับตั้งเป้าหมาย และกระดานสรุปสำหรับประวัติ

## วงจรโฟกัส

นั่งโต๊ะ → ตั้งเป้าหมายหนึ่งข้อ → กดพร้อม → เจ้าของโต๊ะเริ่มเมื่อทุกคนพร้อม → โฟกัส 25 นาที → บันทึกผล → พัก 5 นาที → ตั้งเป้าหมายและพร้อมใหม่ แต่ละโต๊ะใช้รอบของตนเอง เริ่มคนเดียวได้ ไม่มี pause ทั้งโต๊ะหรือเริ่มรอบใหม่อัตโนมัติ

ผู้มาช้ารอรอบถัดไป หรือออกไปทำรอบส่วนตัว มีรอบที่กำลังทำได้หนึ่งรอบต่อบัญชี ระหว่างโฟกัสอวาตาร์นั่งอยู่ ผู้ใช้ยุติรอบและลุกได้โดยไม่หยุดเพื่อน ช่วงพักลุกได้โดยไม่สำรองที่นั่ง

เป้าหมายแก้ก่อนเริ่มและล็อกเมื่อเริ่ม ผลเป็นสำเร็จ / บางส่วน / ยังไม่สำเร็จ อุปสรรคและสิ่งที่จะทำต่อไม่บังคับ แก้ reflection ภายหลังได้ ข้อความเป้าหมายเป็นส่วนตัวโดยค่าเริ่มต้นและเลือกแชร์ก่อนเริ่มได้ สมาชิกโต๊ะเห็นสถานะและผลเป้าหมาย อุปสรรคและสิ่งที่จะทำต่อเป็นส่วนตัว

ต้องบันทึก reflection ก่อนพร้อมรอบถัดไป หากยังไม่ตอบออกจากโต๊ะเพื่อบันทึกภายหลังได้ เป้าหมายที่แชร์เห็นเฉพาะสมาชิกโต๊ะปัจจุบัน ออกจากโต๊ะแล้วไม่เปิดประวัติเป้าหมายให้ผู้อื่น

## ห้องและความต่อเนื่อง

เจ้าของโต๊ะคือคนเริ่มนั่งคนแรก เจ้าของห้องดูแลสมาชิกและปิดห้องได้ เมื่อเจ้าของออกให้สมาชิกที่อยู่ในขอบเขตนั้นนานที่สุดรับหน้าที่ต่อ รอบไม่หยุดเพราะเจ้าของโต๊ะออก

เน็ตหลุดสำรองที่นั่ง 60 วินาที แล้วปล่อยที่นั่ง แต่รอบเดิมยังเดินต่อ เมื่อกลับมาคืนสถานะตามเวลาเดิม ถ้าที่นั่งถูกใช้ให้ปรากฏที่ทางเข้าและติดตามรอบผ่าน UI ห้องว่าง 5 นาทีแล้วปิดและรหัสใช้ไม่ได้

หนึ่งบัญชีควบคุมโลกหนึ่งแท็บ เปิดแท็บใหม่แล้วโอนการควบคุม ไม่สร้างอวาตาร์หรือรอบซ้ำ การออกจากห้อง การถูกนำออก หรือห้องถูกปิดยุติการเข้าร่วมและเก็บเหตุผลไว้ ยังบันทึก reflection ได้ ปิดห้องระหว่างมีรอบต้องยืนยันก่อน

บัญชีที่ถูกนำออกกลับเข้าห้องเดิมไม่ได้ตลอดอายุห้อง ไม่มีการแบนข้ามห้อง

## Asset pack 2D

สร้าง asset pack สำหรับ demo นี้เป็นงานในขอบเขต ใช้ธีม Cozy Campus Library ชุดเดียว รองรับแมพเดียว การเดิน การนั่ง และวัตถุโต้ตอบ รายการขั้นต่ำยืนยันแล้ว:

- Tileset พื้น ผนัง และขอบห้อง
- โต๊ะ เก้าอี้ ชั้นหนังสือ กระดานเป้าหมาย และกระดานสรุป
- ของตกแต่งมุมพัก เช่น โซฟา ต้นไม้ และโคมไฟ
- อวาตาร์ preset 4 แบบ มีท่ายืน เดิน 4 ทิศ และนั่ง
- PNG โปร่งใสและ spritesheet พร้อมข้อมูลตำแหน่งเฟรม จุดยึด collision และจุด interact ที่ใช้ใน demo

รายละเอียดขนาด tile และกระบวนการผลิตยังไม่ล็อก ต้องตรวจ asset ในฉากจริงก่อนถือว่าเสร็จ

### ทิศทางความเฉพาะตัว

อ้างอิงโครงพื้นที่และการจัดองค์ประกอบบางส่วนจาก [LimeZu Modern Office](https://limezu.itch.io/modernoffice) และ [Modern Interiors](https://limezu.itch.io/moderninteriors) ได้ ผู้ใช้เน้นสร้างงานที่ unique จึงออกแบบรูปทรงเฟอร์นิเจอร์ อวาตาร์ ลวดลาย สัดส่วนรายละเอียด และการจัดห้องสำหรับ Connecta Focus โดยเฉพาะ ใช้โทนครีม ไม้ และเขียวหม่นของ Cozy Campus Library เป็นทิศทางหลัก Reference เป็นแรงบันดาลใจสำหรับงานสร้างใหม่ ไม่ใช่ข้อกำหนดให้นำไฟล์ asset ของทั้งสองชุดมาใช้

## แชต

แชตทั้งห้องผ่านแผงกาง/หุบด้วยปุ่มวงกลม ไม่ใช่ข้อความเหนืออวาตาร์ เริ่มโฟกัสหุบครั้งเดียว เปิดอ่านและตอบได้ ไม่มีเสียง ช่วงพักไม่เปิดให้อัตโนมัติ

ขณะหุบแสดงเลขข้อความที่ยังไม่อ่าน ไม่นับข้อความตนเอง เปิดแผงและอยู่ท้ายรายการถือว่าอ่าน หากเลื่อนอยู่ด้านบนมีปุ่มกลับไปข้อความใหม่ จำกัด 200 ตัวอักษรต่อข้อความ เก็บ 100 ข้อความล่าสุดขณะห้องเปิด ผู้มาใหม่อ่านได้ ปิดห้องแล้วล้างแชต

## ประวัติและสรุป

เก็บประวัติถาวรส่วนบุคคลข้ามการเปิดเว็บ แสดงวันนี้หรือ 7 วันล่าสุด: เวลาเข้าร่วมรอบ จำนวนรอบครบเวลา ผลเป้าหมาย และจำนวนที่ยังไม่บันทึกผล เวลาเข้าร่วมนับเฉพาะช่วงเชื่อมต่อ ไม่ใช่หลักฐานยืนยันสมาธิ ครบเวลาไม่เท่ากับทำเป้าหมายสำเร็จ

## โครงสร้างเทคนิค

React + TypeScript สำหรับ UI, Phaser สำหรับโลก 2D, Node.js + Socket.IO สำหรับ API/realtime ใน backend เดียว และ PostgreSQL สำหรับข้อมูลถาวร เซิร์ฟเวอร์ตัดสินสิทธิ์ ที่นั่ง เวลา และการบันทึกซ้ำ ตำแหน่งเป็นสถานะชั่วคราว

เริ่มรันในเครื่อง สาธิตผู้ใช้จริงสองบัญชีผ่านสองเบราว์เซอร์ การเผยแพร่ผ่านอินเทอร์เน็ตเป็นขั้นถัดไป

## เกณฑ์รับ demo

- สองบัญชีเข้าห้องเดียวกัน เดิน เห็นกัน โต้ตอบ และนั่งโดยไม่แย่งที่นั่งสำเร็จพร้อมกัน
- ตั้งเป้าหมาย กดพร้อม เริ่มรอบร่วม และเห็นเวลาเดียวกัน
- เปิด/หุบแชต อ่านและตอบระหว่างโฟกัส พร้อมเลขข้อความใหม่โดยไม่มีเสียง
- ยุติรอบของตนเองโดยไม่หยุดเพื่อน และบันทึกผลได้
- Refresh/reconnect แล้วเวลาไม่รีเซ็ต ไม่สร้างรอบหรือผลซ้ำ
- ประวัติและสรุปแยกเวลา ผลเป้าหมาย และรายการยังไม่ตอบ
- ทดสอบความจุ 8 คนเพิ่มเติมจากวงจรขั้นต่ำ 2 คน

## เลื่อนออก

Matching, Task CRUD, daily/weekly goals, custom duration, เป้าหมายกลุ่ม, กราฟรายวิชา, leaderboard/streak, เสียง/วิดีโอ, ข้อความส่วนตัว, แมพหลายแบบ, map editor, avatar customization และระบบเดินบนมือถือ

## การประเมิน

เกณฑ์รับ demo ตรวจการทำงานและความถูกต้องของข้อมูล การสรุปว่าเพิ่ม productivity ต้องผ่านสัมภาษณ์และทดลองกับนักศึกษาจริงตามข้อเสนอฐาน ไม่อนุมานจากเวลา timer หรือผล demo

ผู้ให้บริการ auth, schema/API, ORM และความถี่ movement ยังไม่ตัดสินใจ เลือกตอนเริ่มพัฒนาโดยให้ demo ใช้งานได้ก่อน การสร้าง asset pack อยู่ในขอบเขตแล้ว
